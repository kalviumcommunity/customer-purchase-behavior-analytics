# Customer Purchase Behavior Analytics

Capstone project: a practical analytics platform for local businesses.

## Project Idea

Customer Purchase Behavior Analytics is a data analytics platform for
local businesses. It will turn transaction data into practical insights
about purchasing patterns, customer value, and customer engagement.
The platform will calculate Recency, Frequency, and Monetary (RFM)
metrics, segment customers, identify high-value and at-risk customers,
and present the results through an easy-to-use dashboard.

## About

A data analytics platform designed to help local businesses understand
customer purchasing behavior using transaction data.

## Problem

Local businesses often have transaction data but lack systematic
methods to analyze customer behavior.

## Objectives

- Analyze customer purchasing behavior
- Calculate RFM metrics
- Segment customers
- Identify valuable and at-risk customers
- Generate business insights

## Capstone Day-by-Day Plan

### Day 1: Understand and plan

- Finalize the problem statement, target users, and project scope.
- Review the existing objectives, roadmap, and initial user flow.

### Day 2: Prepare the data

- Inspect the transaction dataset and document its fields.
- Clean missing values, duplicates, invalid records, and inconsistent formats.

### Day 3: Explore the data

- Perform exploratory data analysis with Python, Pandas, and NumPy.
- Identify sales trends, purchasing patterns, and useful business metrics.

### Day 4: Build customer metrics

- Calculate Recency, Frequency, and Monetary values for each customer.
- Validate the calculations and document the assumptions used.

### Day 5: Segment customers

- Create customer segments from the RFM results.
- Identify high-value, loyal, new, and at-risk customer groups.

### Day 6: Create the analytics prototype

- Build charts and tables that communicate the main findings.
- Review the prototype against the needs of a local business owner.

### Day 7: Design the application

- Define the data model, backend API, frontend views, and dashboard flow.
- Refine the UX based on the planned customer and business workflows.

### Day 8: Integrate the application

- Connect the data pipeline to the backend and database.
- Implement the first dashboard views and customer analytics workflow.

### Day 9: Add advanced insights

- Explore churn prediction, recommendations, and AI-generated business insights.
- Select only the advanced features that are realistic for the project scope.

### Day 10: Test and prepare the final delivery

- Test the analytics, application workflow, and dashboard usability.
- Complete documentation, deployment preparation, and the final presentation.
